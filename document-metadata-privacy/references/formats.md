# 格式分流与复查

## Office 与 WPS 的 DOCX / PPTX / XLSX

它们是 OOXML ZIP 包，常见属性在 `docProps/core.xml`、`app.xml`、`custom.xml`。脚本也识别 Content_Types 声明的其他属性部件位置。

核心属性包括 creator、lastModifiedBy、created、modified、lastPrinted、revision、title、subject、description、keywords 等；默认全部清空。扩展属性只删除指定的身份/软件/编辑时间字段，保留统计及结构信息。HyperlinkBase 会影响相对链接，故保留并报告。自定义属性全部清空，因此有依赖属性的动态字段时必须先评估。

脚本只报告而不自动破坏这些内容：

- Word：批注作者与时间、修订、隐藏文字、页眉页脚、模板链接、自定义 XML、DOCPROPERTY/DOCVARIABLE。
- PPT/WPS 演示：演讲者备注、批注与人员列表、隐藏幻灯片、媒体、嵌入对象。
- Excel/WPS 表格：批注、隐藏工作表、外部连接、嵌入对象；还需人工检查名称、缓存、隐藏行列等脚本未穷尽的区域。
- 通用：缩略图、图片 EXIF/XMP、内嵌 PDF 或工作簿、外链目标中的用户名/路径、文档正文可见信息。

关键词扫描只给出部件名称，不构成身份识别或完整扫描。脚本不会递归清理嵌套文件，也不会检查图像像素、二维码、任意二进制字符串、所有厂商扩展、隐藏对象或内容来源凭证。

如有 Microsoft Office 桌面版，可在副本上使用“文件 → 信息 → 检查问题 → 检查文档”。逐项选择检查与移除；“全部删除”可能不可逆，特别是修订、备注和隐藏内容。操作后重新检查最终输出。

## WPS 特别说明

WPS 文字、演示、表格保存为 `.docx/.pptx/.xlsx` 后使用同一清理方法；WPS 导出的 PDF 单独清理。Application 中的 WPS/Kingsoft 字样和其他生成器名称一样处理，不替换成 Microsoft Office 或人名。

WPS 官方开放平台记录 `Document.RemovePersonalInformation = true`，用于文档下一次保存时删除批注、修订和属性中的用户信息。仅在已连接的 WPS 文字环境暴露该 API 时使用；不要假定所有平台、版本、演示或表格对象都支持。该开关会改变协作信息，应结合本次授权范围；它不能代替导出文件复查。

WPS UI 菜单名称随版本变化。先检查实际“文件信息/属性/安全/隐私”相关功能，避免凭空承诺某个按钮存在。再次用 WPS 保存可能重新写入软件名、版本或用户信息，因此最终清理必须在最后一次保存后。

`.wps/.et/.dps` 和 `.doc/.xls/.ppt` 不能按 ZIP XML 文件处理。通过 WPS/Office 实际“另存为”相应 OOXML 格式，再检查排版、公式、动画、链接等并清理。不要直接改扩展名。如用户必须保留旧格式，使用该应用提供的属性清理功能，在最终旧格式上复查；没有可用工具就说明尚未完成，而非声称已清理。宏文件单独处理，不能转存时丢失宏。

## PDF

Info 字典与 XMP 是两套不同机制；XMP 可能存在于目录、页面或其他对象上。脚本遍历可达对象并去掉 Metadata 引用，通过完整重写清除被丢弃的对象。只更新属性后做增量保存可能保留旧字节。

批注标题/作者/日期、表单值、附件、图片内部元数据、可见文字和软件结构特征不属于此脚本已清除范围。PDF 的文件 ID 和正常结构也可能保留。脚本没有判断“是否 AI 生成”的功能。

PDF/A、PDF/UA 的 XMP 可承载符合性信息，不能为了清空属性而破坏这些标准；签名文件任何修改都可能影响签名。需要专门的保留符合性/重新签名流程，未经授权不移除来源凭证或签名。

## 其他文档

- ODT/ODS/ODP：使用 LibreOffice 等格式原生工具的文档属性及个人信息清理功能；检查 `meta.xml` 和嵌入资源。脚本不直接支持。
- RTF：使用格式解析器/原应用处理 info 属性组，不用全文件正则替换正文。
- HTML：检查生成器/作者 meta、注释和资源信息；保持实际内容与署名要求。
- Markdown/TXT/CSV：通常没有 Office 式作者属性；检查 frontmatter、注释、可见署名及附带文件。CSV 公式和内容不因隐私整理而改变。
- 云端文档：下载的文件属性与云端账号、版本历史、活动记录是不同层面；清理导出副本不会删除云端记录。

文件系统时间、操作系统索引、云端历史和外部已收到的副本不由此技能处理。清空属性不是来源伪装，缺少元数据和固定 ZIP 时间本身也可能显示文件经过处理。
